# NWW Reborn — интерактивный атлас

Откройте `dist/index.html` в браузере. Это автономный файл: интернет, сервер и установка зависимостей для просмотра не нужны. Можно отправить этот файл другому человеку.

Масштаб: колесо, кнопки +/−, жест двумя пальцами. Перемещение: перетаскивание или стрелки после фокусировки карты. Клик по стране открывает карточку. Поиск работает по русскому имени и тегу; `/` переводит фокус в поиск. Легенда фильтрует список и приглушает другие категории. SVG выгружается с легендой, без активного фильтра и обрезки текущим масштабом.

## Источники и классификация

Границы получены из установленной HOI4 `map/provinces.bmp`, `map/definition.csv` и эффективных `history/states/*.txt`, с приоритетом одноимённых файлов мода. Срез: 1 января 1936 года, все DLC включены; учитываются стартовые условные передачи владений в истории регионов. Инициализация кампании не воспроизводится игровым движком: это карта исходников, не экспорт игрового сохранения. Контуры следуют пиксельным границам карты игры, без подмены современной географией.

- Зелёный: LTB, MKN, UKR, SOV, AUS, TUR, GER — переработки с новыми фокусами и механиками, согласно README проекта и страновым файлам.
- Оранжевый: HUN, AFG — адаптированный архивный контент. Источники переноса: `docs/legacy_import.json`, `docs/legacy_focus_migration.md`.
- Белый: отсутствует собственное дерево NWW; наличие ванильного/DLC дерева не учитывается.
- Белая штриховка: CRO, BYE, LIT, LAT, EST — небольшие новые деревья; FRA — новая разработка в параллельно появившихся рабочих файлах, полная готовность которой пока не подтверждена документацией проекта. Это явно выделенное исключение к трём основным категориям, чтобы не искажать состав контента.

Отсутствующие на старте теги представлены в списке с пометкой, без закрашивания чужих земель. Счётчики легенды считают только существующих владельцев. Список по умолчанию показывает страны с контентом, включая будущие страны-преемники. Классификация зафиксирована в генераторе; наличие файла само по себе не означает полную проработку. Сохранение старых ID в полностью переработанной стране не делает её Legacy.

Генератор считает только прямые focus/shared_focus определения, обходит связанные общие ветки и исключает постоянно скрытые определения совместимости. Файлы, числа фокусов, статусы и владение регионами встроены в HTML; удобный реестр стран — `classification.json`.

## Обновление

Из корня мода:

```powershell
python tools/build_content_atlas.py --game "D:/Steam/steamapps/common/Hearts of Iron IV"
```

Нужен Pillow, используемый остальными инструментами проекта. Генератор не меняет игровые файлы. При появлении других условий в стартовых передачах владений сборка останавливается с ошибкой, чтобы не выдавать неподтверждённый результат.

Исходники интерфейса находятся в `src/`. После правок пересоберите HTML. Новая графика и изменения игровых механик не добавлялись.
