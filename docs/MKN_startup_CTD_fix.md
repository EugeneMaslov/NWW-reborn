# Исправление падения при первоначальной загрузке MKN

## Подтверждённые данные

Сбой `hoi4_20261014_202123`: 14 октября 2026, 20:21:23, HOI4 `Operation Postern v1.19.3.0.c01a`, Linux, `--debug`, активен только NWW Reborn. Игра записала `SIGSEGV` в `exception.txt`; файла `exceptions.log` в этой версии отчёта нет. Стек содержит адреса без доступных символов: точную функцию разыменования по нему установить нельзя.

В `error.log` непосредственно перед падением:

| Файл и исходная строка | Сообщение движка | Исправление |
| --- | --- | --- |
| `common/decisions/MKN_ukr_border_decisions.txt:34` | `unexpected token … (2)` после `mkn_consecutive_border_wars >= 2` | Именованное сравнение `var`, `value`, `compare` |
| `common/national_focus/MKN_frontier_focuses.txt:12`, `:223` | `Not a valid value: UKR` | `UKR = { exists = yes }` |
| `common/national_focus/MKN_frontier_focuses.txt:49`, `:84`, `:119`, `:153`, `:190`, `:230` | Ошибки токенов на включительных сравнениях | `compare = greater_than_or_equals` |
| `common/national_focus/MKN_frontier_focuses.txt:234–306` | После ошибки чтения последующие поля воспринимаются как триггеры; финальный `shared_focus` не загружается | Исправлена первичная грамматика сравнения |
| Последняя запись `nationalfocus.cpp:2472` | `MKN_conclude_total_war: Couldn't find dependency MKN_conclude_kharkiv_treaty` | Обе взаимоисключающие цели снова корректно определены |
| `common/decisions/MKN_decisions.txt:206–208`, `:248–249`, `:322–323` | Региональные триггеры выполнялись в области страны | Обёртка `FROM = { … }` в трёх `target_trigger` |
| `common/decisions/MKN_decisions.txt:479`, `:488` | `Invalid trigger 'num_owned_states'` | Динамическая переменная внутри `check_variable` |

Первая подтверждённая причина повреждения дерева — неподдерживаемый короткий синтаксис `>=`/`<=`. Он сбивает разбор фокуса; ссылка на отсутствующий финальный фокус — последняя ошибка до SIGSEGV. Это наиболее вероятная причина самого падения. Несимволизированный стек и отсутствие повторного запуска на момент анализа не позволяют утверждать точную C++-функцию сбоя.

## Исправленные формы

```pdx
check_variable = {
    var = mkn_ukr_escalation_level
    value = 2
    compare = greater_than_or_equals
}
UKR = { exists = yes }
check_variable = { num_owned_states > 0 }
target_trigger = {
    FROM = {
        is_owned_and_controlled_by = UKR
    }
}
```

Все включительные сравнения исправлены в решениях, фокусах, событиях и эффектах фронтира. Прямые проверки количества областей исправлены также в гражданской войне и советской интервенции. Ошибочные `exists = event_target:…` заменены на нативный `has_event_target`, а проверки советских стран интервенции выполняются в соответствующей области страны. Игровые пороги и эффекты сохранены.

## Проверка текстур, скобок и карты

Шаги выполнены в запрошенном порядке: журналы → DDS → скобки → карта → исправления.

Проверены 93 DDS из восьми последних коммитов и каталога фронтира: 85 несжатых RGB32 с альфой и 8 DXT1. Проверены magic, длины заголовков 124/32, размеры, pitch, mip-count/флаги, вычисленный размер всех уровней и полное декодирование. Один уровень без mipmaps корректен; все 11 текстур фронтира имеют стандартные маски BGRA `00ff0000/0000ff00/000000ff/ff000000`, совпадающие с нативными изображениями фокусов. Некорректных файлов не найдено. Они не перекодировались и не подменялись. Утверждать полную совместимость GPU только по декодированию нельзя, но журналы указывают на разбор скрипта и не содержат ошибки этих текстур.

50 недавно изменённых `.txt/.gui/.gfx` прошли лексическую проверку парных скобок с исключением комментариев и строк. Баланс скобок не был причиной: прежний общий парсер допускал операторы, которые нативный загрузчик здесь не принимает.

Провинции 429 и 9571 существуют в установленном `map/definition.csv`, являются сушей и встречаются ровно один раз, в регионе 1082. Регион 200 их не содержит. Победные точки 429/11405 входят в соответствующие регионы. Дамба региона 200 находится в его провинции 11405; остальные здания используют допустимую область региона. Дубликатов IDs регионов и провинций в истории мода нет. Карта не менялась.

## Образцы установленной игры и защита от повторения

- `documentation/triggers_documentation.md`, разделы `check_variable`, `exists`, `has_event_target`: именованные включительные сравнения, булево значение существования страны и наличие сохранённого event target.
- `common/national_focus/netherlands.txt:4650–4654`, `:4754–4755`: `greater_than_or_equals` / `less_than_or_equals`.
- `common/decisions/EST.txt:534`: переход в выбранный регион `FROM`.
- `documentation/dynamic_variables_documentation.md`, `num_owned_states`: встроенная переменная количества владений.
- `common/scripted_effects/INS_scripted_effects.txt:1482`: `has_event_target`.
- `gfx/interface/goals/goal_generic_construct_civilian.dds`, `goal_generic_production.dds`: нативные 32-битные маски цвета/альфы.

`tools/hoi4_script.py` теперь отдельно проверяет грамматику загрузчика. Валидатор отклоняет сырые двухсимвольные операторы, не булевый `exists`, использование `num_owned_states` как триггера и прямые региональные условия в `target_trigger`. Модели сценариев читают тот же нативный формат сравнения. Проверка на исходных версиях четырёх проблемных файлов из HEAD отклоняет прежние ошибки, а исправленные файлы проходят. Отдельно проверены пять ошибочных форм и пять допустимых эквивалентов.

Общая проверка: 124 сценария распада, 24 интервенции, 43 фронтира. Проверки локализаций, зависимостей дерева, старого контента и `git diff --check` проходят. Запрошенный путь `D:/Steam/…` отсутствует; используется установленный Linux-каталог игры.

Повторная загрузка игры и свежий журнал нужны, чтобы подтвердить прекращение CTD. На момент статической проверки такого подтверждения нет.
