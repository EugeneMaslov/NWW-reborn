# Восстановленные источники портретов MKN

Исходные фотографии `docs/for-gen/photo-eugen-general.jpg`,
`docs/for-gen/dmitruk-tratishov-2.jpg` и `docs/for-gen/man.jpg` отсутствуют
в этой рабочей копии. Эти PNG получены без потери пикселей из сохранившихся
игровых DDS. Это восстановленные экспорты, а не оригинальные фотографии.
Высокое разрешение исходных фотографий таким способом восстановить нельзя.

`docs/art/MKN_personnel_assets.json` сохраняет прежние пути и SHA-256
в полях `original_source` и `original_source_sha256`. Поля `source` и
`source_sha256` указывают на доступные PNG; `export_sha256` проверяет
неизменность утверждённого DDS. Сборщик использует эти PNG, когда исходные
JPG недоступны, и сохраняет сведения о происхождении при повторной сборке.

При появлении оригинальных JPG сборщик снова использует их. Для советника
Евгена сохранился отдельный рисованный оригинал высокого разрешения;
он не заменялся восстановленным изображением.
