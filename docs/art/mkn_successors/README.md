# Видимые портреты преемников MKN

Прежняя `gfx/leaders/MKN/communal_council.dds` имела размер 156×210, непрозрачную альфу и RGB **(0, 0, 0) во всех пикселях**. Её одновременно использовали крестьянский совет, ревком и Осип Цебрий. Это был чёрный заполнитель, а не проблема имени файла.

Встроенным **imagegen** созданы два оригинала:

| Назначение | Оригинал | Точный промпт | Игровой экспорт |
| --- | --- | --- | --- |
| Осип Цебрий | [osyp_tsebriy.png](osyp_tsebriy.png) | [osyp_tsebriy.prompt.txt](osyp_tsebriy.prompt.txt) | `gfx/leaders/MKN/osyp_tsebriy.dds`, 156×210 |
| Коллективный совет / ревком | [communal_council.png](communal_council.png) | [communal_council.prompt.txt](communal_council.prompt.txt) | `gfx/leaders/MKN/communal_council.dds`, 156×210 |

Портрет Цебрия — **художественная интерпретация без подтверждённого фото-референса**, а не восстановленное историческое сходство. Фигуры коллективного совета вымышлены. CLI/API для генерации не использовались. Оригиналы и промпты сохранены в проекте; игровые ссылки не зависят от внешнего каталога генерации.

Советник с именем Цебрия использует отдельный экспорт `gfx/interface/ideas/nww_portraits/MKN_osyp_tsebriy.dds`: холст **65×67**, занятая альфа-область **(4, 2, 61, 60)**, последние семь строк прозрачны. Для точной альфы карточка сохранена в несжатом DDS RGBA. Лидерские портреты остаются отдельными и непрозрачными.

[Превью в игровых размерах](preview.png). [Манифест размеров и SHA-256](assets.json).

Техническая пересборка: `python tools/build_mkn_successor_portraits.py`. Она только масштабирует/кадрирует сохранённые оригиналы и экспортирует DDS. Проверены также действующие крупные портреты Дмитрука Тратишова и Волина: они имеют размер 156×210 и ненулевые пиксели. Портрет монарха Махно не менялся. Для старых сохранений известным преемникам назначается правильный спрайт через `set_country_leader_portrait`, без пересоздания правителя, смены политики или повторных наград.
