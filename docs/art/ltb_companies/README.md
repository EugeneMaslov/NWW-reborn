# Обновлённые эмблемы предприятий LTB

Восемь эмблем перерисованы встроенным imagegen по собственным исходным знакам старого мода. Сохранены узнаваемые силуэты, монограммы и основные цвета; выбран стиль металлических и эмалевых промышленных знаков 1930-х годов.

- Исходные изображения: `references/*.png` (точная конверсия прежних DDS).
- Сгенерированные PNG: `generated/*.png`.
- Точные промпты, входы и игровые пути: [generation.json](generation.json).
- Игровые файлы: `gfx/interface/ideas/LTB/idea_nww_company_*.dds`, прозрачные 64×64.
- Регистрация: `interface/nww_companies.gfx`; прежние имена спрайтов сохранены, чтобы MIO и конструкторы использовали одну эмблему.
- Предпросмотр в игровом размере: [ltb_company_icons_preview.png](../../ltb_company_icons_preview.png).

Пересборка: `python tools/build_ltb_company_icons.py`. Она только подготавливает игровой формат и сохраняет оригиналы отдельно.
